# Personal Portfolio Website

Individual Web Development Project built using **HTML5**, **CSS3**, and **JavaScript**.

## Features Included
1. **Home Section** – Introduction, student avatar, welcome message, and quick action buttons.
2. **About Me Section** – Background, interests, and career goals.
3. **Education Section** – Timeline of B.Tech CSE (AI), Class 12th, and Class 10th.
4. **Skills Section** – Technical and non-technical skill progress bars.
5. **Projects Section** – Project cards with tech tags and interactive "View Details" modal.
6. **Hobbies & Interests Section** – Cards highlighting personal hobbies.
7. **Achievements Section** – Academic and technical milestones.
8. **Contact Section** – Contact info + client-side JavaScript validated form.
9. **Dark Mode & Light Mode** – Theme toggle button powered by JavaScript and CSS variables.
10. **Interactive Navigation** – Sticky navbar with active link highlighting and smooth scroll.
11. **Responsive Design** – Mobile hamburger menu and responsive CSS Grid/Flexbox layouts.
